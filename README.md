# <img src="https://github.com/astroid-app/v2/blob/main/assets/Astroid%20Logo%20no%20bg.png?raw=true" width="30px" height="30px">Astroid Website (Frontend)

**This is a rework of the original site, updated to use PHP and TailwindCSS. If you are looking for the original site, you may find it [here](https://github.com/astroid-app/website)**

This is an remake for the Astroid website made using TailwindCSS, it includes following pages that have been transferred:

- Imprint
- Privacy Policy
- Terms of service
- Some cat ASCII art because I wanted to
- Some smol hints for the new dashboard design
